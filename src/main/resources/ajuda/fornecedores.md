# Fornecedores

Cadastro dos fornecedores.

## Como usar

- Procure pela razão social, pelo nome fantasia, pela cidade ou pelo CPF/CNPJ.
- Escolha o fornecedor na lista para ver e alterar os dados; **Salvar** grava.
- O CNPJ pode ser numérico ou no novo formato com letras; o sistema confere os dígitos.

## Dica

Fornecedor com compras não pode ser excluído: inative-o.
