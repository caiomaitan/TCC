# Clientes

Cadastro dos clientes, com o histórico de compras, o crédito e o crediário.

## Como usar

- Procure pelo nome, pelo CPF/CNPJ (inteiro ou parte) ou pelo telefone.
- Escolha o cliente na lista para ver e alterar os dados; **Salvar** grava.
- A aba **Compras** mostra o histórico, o total gasto, o ticket médio e os produtos mais comprados.
- A aba **Crédito** mostra o saldo de crédito (vale-troca e cashback) e o extrato.

## Dados pessoais (LGPD)

- **Exportar** gera um arquivo com os dados do cliente, para entregar a ele quando pedir.
- **Anonimizar** (só o supervisor) apaga os dados pessoais e mantém as vendas.

## Dica

O CPF, o telefone e o CEP ganham a máscara sozinhos ao sair do campo.
