# Fiscal

Dados fiscais dos produtos: NCM, CEST, origem e perfil tributário.

## Abas

- **Produtos**: os dados fiscais de cada produto e a aplicação de um perfil em vários produtos de uma vez.
- **Perfis tributários**: modelos com a tributação usada pela loja, para não preencher produto por produto.
- **Tabelas NCM e CEST**: a consulta das tabelas oficiais.

## Dica

O relatório de inconsistências fiscais (Relatórios) aponta os produtos sem NCM, com NCM inválido ou sem perfil. O sistema não emite nota fiscal: estes dados servem para conferir o cadastro com o contador.
